# TTS Broadcast Card for Home Assistant Lovelace

A sleek, reactive text-to-speech broadcast card with pre-broadcast chime support, zero-script configuration, multi-language Edge TTS neural voice detection, and live state feedback.

## Key Highlights
- **Zero Backend Scripts Needed**: 100% frontend orchestration calling native HA services.
- **Pre-broadcast Notification Chime**: Built-in chime trigger with configurable speaker transition delay.
- **Multi-language Edge TTS Voice Auto-Detection**: Chinese (Xiaoxiao), English (Jenny), Japanese (Nanami), and Korean (SunHi).
- **Graphical Card Editor**: 4-tier visual settings form built with native `<ha-form>`.
- **Live Status Pulse & Failsafe Watchdog**: Real-time state reflection with a 16s watchdog timer.

Check the repository [README](https://github.com/lucayunxiao/tts-broadcast-card#readme) for full installation and configuration instructions.
